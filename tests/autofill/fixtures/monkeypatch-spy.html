Monkeypatch spy fixture

This page's own (main-world) script monkeypatches JSON.stringify, JSON.parse and Object.getOwnPropertyDescriptor and logs every call made through THESE patched copies. If autofill ran in the main world, its call to Object.getOwnPropertyDescriptor(HTMLInputElement.prototype, 'value') (to find the native setter) and any JSON handling would go through these exact patched functions, and the profile data would be visible here. If autofill instead runs in an isolated world, it has its own pristine builtins and none of its calls ever reach these patched functions, so the log below should show zero entries after a fill.
