React-like value tracking fixture

This page reimplements React's own input value-tracking trick (react-dom/cjs/react-dom.development.js, inputValueTracking.trackValueOnNode): it shadows each input's `value` property with an own-property accessor that records the last value written *through that accessor*, then on a native bubbling 'input' event compares the real (prototype-getter) value against the recorded one. React only fires its synthetic onChange when they differ -- which is exactly what happens when an external script (a password manager, or this autofill userscript) sets .value via the *native* setter obtained straight from the prototype descriptor, bypassing this instance property. If autofill's isolated-world fill still trips this exact check, it proves compatibility with real React forms, not just plain DOM ones.
